
# Bella Cavalli — Beleza & Bem-Estar

Site institucional com sistema de agendamento online para serviços de estética e bem-estar.

## Tecnologias

- Angular 21
- TypeScript
- SCSS
- Laravel (futura implementação)

## Funcionalidades planejadas

- Página inicial responsiva
- Catálogo de procedimentos
- Agendamento online
- Painel administrativo da profissional
- Integração com WhatsApp

## Identidade visual

- Champanhe
- Dourado
- Vinho
- Marfim

## Desenvolvimento

Projeto desenvolvido por etapas, com versionamento no GitHub.
